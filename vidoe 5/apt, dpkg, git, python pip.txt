Key idea:
A package may depend on other packages. apt handles those dependencies automatically.
2. APT — ⭐ Most important
Install / remove / update
sudo apt update
sudo apt install <package>
sudo apt remove <package>
sudo apt purge <package>
sudo apt upgrade
sudo apt full-upgrade

- update → updates the package information/list from repositories
- install → installs
- remove → removes the application but keeps user/config data
- purge → removes application + configuration data
- upgrade → upgrades packages
- full-upgrade → can remove packages that are no longer required for the upgrade
Fix dependencies
sudo apt --fix-broken install

3. Finding / inspecting packages
apt list
apt list --installed
apt list --installed | grep <name>

apt search <package>
apt show <package>

apt -h

- list → available packages
- --installed → installed packages
- search → searches packages
- show → information about a package
- -h → help
4. Repositories

       ├── package

A repository is a server/storage location containing packages.
APT checks the configured repositories when installing software.
On Parrot, the video shows the repository configuration through:
sudo apt edit-sources

5. DPKG
sudo dpkg -i <file.deb>
dpkg -l

dpkg
 ↓
requires .deb file
 ↓
doesn't automatically handle dependencies

Use dpkg when you have a .deb package you want to install manually.
6. Other package managers
Aptitude
sudo aptitude

High-level package manager with an interactive interface.
Snap
sudo apt install snapd
sudo snap install <package>

Example:
sudo snap install code --classic

Python
pip3 install -r requirements.txt

pip3 → Python 3 packages/dependencies.
Ruby
gem install <package>

gem → Ruby packages.
7. Git + GitHub
Install Git:
sudo apt install git

Clone a GitHub repository:
git clone <repository-url>

Then:
cd <project>

For a Python project:
pip3 install -r requirements.txt
python3 <script>.py

Typical workflow
GitHub repository
       ↓
   git clone
       ↓
   project files
       ↓
requirements.txt
       ↓
     pip3
       ↓
install dependencies
       ↓
 run Python script

⭐ What you actually need to remember
If you want the ultra-short version, these are the commands I'd prioritize:
sudo apt update

sudo apt remove <package>
sudo apt purge <package>
sudo apt upgrade

apt list --installed
apt search <package>

sudo dpkg -i <file.deb>

And remember the concepts:

apt → repositories → dependencies → high level

snap → Snap Store

pip3 → Python
